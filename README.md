# Проектирование систем и продуктовая веб-разработка
Расчет расхода строительных материалов для кладки стен. Услуги - типы кладочных материалов (кирпич, блоки) разных размеров и нормой расхода раствора на 1 м³ кладки. Заявка - расчет количества кирпича/блоков и кладочного раствора для возведения стены заданных габаритов (длина, высота, толщина).
